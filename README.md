# Hack-The-North

As first year university students, attending university lectures has been a frightening experience. Much different than how it is in high school, with a class of thousands of students, it’s much too easy to lose focus in lectures. One bad night of sleep can lead to valuable information lost and while one may think that only missing one lecture is alright, wait until they see the content they missed on the midterm. That is why we decided to build an Augmented Reality/Mobile application capable of speech to text recognition and a bunch of other useful features such as text summarization and text translation in order to help students with understanding lectures and avoid those days where one may zone out in class. Either use your phone or your headset!

The code for the Unity in C#. Contains the code for the AR, application and UI/UX. Also contains Python Backend. Original [Repo](https://github.com/HTN-heAR/Hack-The-North)
